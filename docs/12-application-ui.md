# Application UI

Only verified facts. If a control is not listed here, write **Not observed / not specified**. Do not invent product UI paths.

## Open Settings

- Sidebar account button, bottom-left (avatar + account name)
- Cmd+,
- Command palette: "Open settings"

No gear icon in the chrome for Settings. No macOS Preferences item.

## Settings tabs

General, Plugins, Team Setup, Appearance, Updates.

### General

Account card: Sign In with Cursor / Sign Out.

### Plugins

- Marketplace search
- Category chips
- Plugin detail: Add / Uninstall
- Accounts + Authenticate
- Installed-plugins button → Your plugins (Installed + Private skills)

### Team Setup

Scripts on every computer assigned to the current team.

### Appearance

Theme: System / Light / Dark.

### Updates

| Control | Meaning |
| --- | --- |
| Update Grok Bot's Computer | Update. Two-click confirm. Keeps files and logins; reinstalls software. |
| Reset Grok Bot's Computer | Reset. Destructive. Last resort. Snapshot. Can lose unsynced work. |
| Update Track | Stable / Nightly |
| Check for Updates | The **app**, distinct from the computer update. |

Do not invent other recovery paths.

## Delete an Agent

Sidebar. Right-click the Agent's row. Delete. Permanent, transcript too, confirm.

Not in Settings. No archive.

The same sidebar delete applies to a Channel: right-click row, Delete, confirm. Agents cannot delete Channels or other Agents.

## Per-Agent info pane

Open:

- Click the Agent name in the chat header, or
- Cmd+Shift+I

Close: X.

Contents:

- Live computer preview (click for full screen)
- Routines
- Channels when a Channel Connector exists
- Members in group chats

Gear beside X → per-Agent settings: avatar, name, title, description, notifications.
