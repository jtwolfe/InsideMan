# ai-sdk

Use when building or debugging AI features on the Vercel AI SDK.

## Steps

1. Match the feature (chat, structured output, tools, streaming) to the SDK API.
2. Prefer Connectors for MCP rather than hand-rolled HTTP.
3. Do not invent UI paths; implement against the app the operator named.
